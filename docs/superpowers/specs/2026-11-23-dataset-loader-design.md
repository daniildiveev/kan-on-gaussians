# Загрузчик табличных датасетов для PyTorch

Дизайн согласован 23 ноября 2026.

## Интерфейс

Эксперимент один раз загружает набор для скалярной регрессии и передаёт одни и те же выборки сравниваемым моделям. Первый встроенный набор — Concrete. Пользователь выбирает размер батча и перемешивание средствами PyTorch.

```python
from torch.utils.data import DataLoader
from mgs_kan.config import ModelSettings
from mgs_kan.data import load_dataset
from mgs_kan.models import make_model

data = load_dataset("concrete", root="data", fold=0, download=True)
train_loader = DataLoader(data.train, batch_size=64, shuffle=True)
model = make_model("mlp", ModelSettings(features=data.n_features))
```

Результат содержит `train`, `val`, `test` и `n_features`. Элемент выборки — пара CPU-тензоров float32: вектор признаков и скалярная цель. После сборки батча формы равны `[batch, n_features]` и `[batch]`. Метод `data.inverse_target(values)` переводит стандартизованные цели и прогнозы в исходные единицы.

## Подходы

- **Только описания таблиц.** Удобно добавлять CSV, но для Concrete пришлось бы описывать группировку рецептов и преобразование возраста отдельным языком правил.
- **Функция для каждого набора.** Поддерживает произвольную подготовку, но даже числовая таблица с одной целью требует нового загрузчика.
- **Общий CSV-загрузчик и функции для особых наборов.** Выбран для единого входа: описание задаёт обычную таблицу, функция Concrete добавляет группировку и преобразование возраста. Разбиение и стандартизация используют общую реализацию.

## Локальные файлы и скачивание

По умолчанию `root="data"`, `fold=0`, `download=False`. Concrete ожидает `root/concrete_compressive_strength.csv`. Существующий файл читается локально при любом значении флага. Для отсутствующего файла ошибка указывает ожидаемый путь и доступный способ получения.

При `download=True` и отсутствии Concrete загрузчик берёт CSV по адресу из официальных метаданных UCI. Загрузка идёт во временный файл рядом с целевым, с конечным тайм-аутом. Проверка заголовка, 1030 строк, восьми признаков, конечности чисел и допустимости возраста и цели предшествует публикации файла. При ошибке итоговый путь остаётся свободен для повтора. Повреждённый локальный CSV выдаёт ошибку и сохраняется для диагностики. В README указываются автор I‑Cheng Yeh, DOI и лицензия CC BY 4.0. [Метаданные UCI](https://archive.ics.uci.edu/api/dataset?id=165) · [Карточка набора](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength)

Предлагаемый способ подключить локальную таблицу в первой версии:

```python
from mgs_kan.data import CsvSpec, load_dataset

data = load_dataset(CsvSpec(filename="houses.csv", target="price"), root="data")
```

Файл читается относительно `root`. Входы — все числовые колонки кроме цели в порядке заголовка. Таблица должна содержать заголовок, числовые признаки и одну числовую цель. Пропуски, неконечные значения и неоднозначные имена колонок приводят к ошибке. Для собственной таблицы без файла и источника ошибка указывает, куда положить CSV. Именованный каталог внутри пакета связывает стабильные имена со встроенными наборами. Начальный каталог содержит Concrete.

## Разбиение и стандартизация

- Для Concrete воспроизвести индексы из `archive/experiments/concrete_order.py`: пять folds, seed 13601, группа по точному совпадению семи ингредиентов. Возраст не входит в ключ. Использовать тот же порядок групп, перестановки и отделение 20% оставшихся групп для validation. К возрасту применить `log1p`.
- Для обычного CSV каждая строка считается отдельной группой. Предлагаю те же пять воспроизводимых folds, пронумерованных от 0 до 4. Ошибка объясняет, если данных недостаточно для трёх непустых выборок. Близкие по смыслу строки требуют собственного правила группировки.
- Для каждого fold вычислить средние и стандартные отклонения признаков и цели только по train, в float64 с делителем N. Применить их к каждой выборке, затем привести тензоры к float32 для активных моделей. Для нулевого стандартного отклонения использовать масштаб 1. Сохранить среднее и масштаб цели для обратного преобразования.
- Текущий объём — числовая табличная регрессия. Код обучения, очереди батчей, категориальные признаки и обработка пропусков остаются отдельными задачами.

## Проверка

Pytest работает офлайн с CSV во временном каталоге и подменой ответа скачивания. Проверить первый вызов, повторное чтение без сети, ошибку при отключённом скачивании, испорченный ответ и успешный повтор. Сравнить индексы Concrete с архивным алгоритмом на одних и тех же строках. Проверить непересечение рецептов, воспроизводимость folds, статистики только по train, обратное преобразование цели и проход одного батча через обе модели. Проверить публичный импорт из установленного пакета.

На этапе реализации однократно проверить реальное скачивание Concrete во временный каталог. Критерий готовности — один и тот же интерфейс работает для UCI и пользовательского CSV, публичная команда из README даёт батч, а архивные исследования сохраняют свои исходники. Размещение внутренних функций и конкретные типы контейнеров остаются на усмотрение исполнителя.
